Foundational Cybersecurity & Networking

Learn Networking: Concepts, Models & Packets

A beginner-friendly guide covering packet fundamentals, network protocols, the 7-layer OSI model, and ethical sniffing.

01

What is a Network Packet?

A network packet is the basic formatted unit of data carried by a packet-switched network. Rather than sending a large file as a continuous stream, data is broken down into small, manageable chunks called packets.

[ Header (Metadata/Routing) ] + [ Payload (Data) ] + [ Trailer (Error Check) ]

Headers contain essential addressing information (Source IP, Destination IP, Ports, Sequence Numbers), enabling intermediate routers and switches to forward the packet accurately to its target destination.

02

What is Packet Sniffing?

Packet sniffing (or packet capturing) is the process of intercepting and logging data packets that traverse a computer network.

  • Legitimate & Defensive: Network troubleshooting, diagnosing packet loss, performance tuning, and intrusion detection (IDS/IPS).
  • Promiscuous Mode: Instructs the Network Interface Card (NIC) to pass all received frames to the OS rather than only frames addressed to its own MAC address.
Ethical Rule: Only sniff networks you own or have explicit written authorization to monitor.
03

What is an IP Address?

An Internet Protocol (IP) address is a logical numerical label assigned to each device connected to a computer network that uses the IP for communication.

IPv4 (32-bit):
192.168.1.100
4 octets, ~4.3 billion total addresses.
IPv6 (128-bit):
2001:db8::1
Hexadecimal, practically limitless space.

IP addresses operate at Layer 3 (Network Layer) and are routable across multiple networks and the global Internet.

04

What is a MAC Address?

A Media Access Control (MAC) address is a unique physical hardware identifier permanently assigned to a Network Interface Card (NIC) by its manufacturer.

Format: 00:1A:2B:3C:4D:5E (48 bits / 6 octets)
00:1A:2B = Organizationally Unique Identifier (OUI - Manufacturer)
3C:4D:5E = Device Network Interface Controller ID

MAC addresses operate at Layer 2 (Data Link Layer) and are used exclusively within local broadcast domains (LANs). They do not route across the Internet.

05

What is a Port Number?

A port number is a 16-bit integer (ranging from 0 to 65,535) used by transport layer protocols (TCP and UDP) to identify specific application processes or network services on a host.

  • Well-Known Ports (0 – 1023): Assigned to standard system services (Port 80 HTTP, 443 HTTPS, 22 SSH, 53 DNS).
  • Registered Ports (1024 – 49151): Vendor and application registered (Port 3306 MySQL, 5000 Flask).
  • Dynamic / Ephemeral Ports (49152 – 65535): Temporarily chosen by client operating systems for outgoing sessions.
06

What is TCP?

Transmission Control Protocol (TCP) is a connection-oriented, reliable transport protocol that guarantees ordered, error-checked packet delivery.

Before data transmission begins, client and server establish a session using the 3-Way Handshake: SYN → SYN-ACK → ACK.

If packets are dropped or damaged during transit, TCP's sliding window flow control detects missing sequence numbers and retransmits them automatically.

07

What is UDP?

User Datagram Protocol (UDP) is a connectionless transport protocol that transmits data packets ("datagrams") without establishing a prior connection, handshake, or acknowledgment feedback.

It provides extremely low latency and minimal header overhead (only 8 bytes compared to TCP's 20-60 bytes).

Ideal for time-critical applications like live gaming, VoIP streaming, and DNS where an occasional dropped packet is preferable to waiting for retransmissions.

08

What is ICMP?

Internet Control Message Protocol (ICMP) is a supporting protocol in the Internet protocol suite used by routers and hosts to communicate error conditions and operational diagnostics.

ICMP does not use port numbers; it is encapsulated directly in IP datagrams (IP Protocol 1).

Common uses: ping sends ICMP Type 8 (Echo Request) and listens for Type 0 (Echo Reply). traceroute maps routes by deliberately triggering ICMP Type 11 (TTL Exceeded) messages.

09

What is DNS?

The Domain Name System (DNS) is a distributed hierarchical naming system that resolves human-readable hostnames (such as packetscope.local) into machine-routable IP addresses.

Resolvers query DNS servers across a hierarchy: Root Servers → TLD Servers (.com, .org) → Authoritative Servers.

Core record types include: A (IPv4 address), AAAA (IPv6 address), CNAME (alias), MX (mail server), and PTR (reverse lookup).

10

What is the OSI Model?

The Open Systems Interconnection (OSI) model is a conceptual framework that standardizes the communication functions of a telecommunication or computing system into 7 distinct abstraction layers.

#LayerProtocol Unit & Examples
7ApplicationHTTP, DNS, SSH, FTP, SMTP
6PresentationSSL/TLS, JPEG, ASCII, Encryption
5SessionSockets, RPC, NetBIOS
4TransportSegments / Datagrams (TCP, UDP)
3NetworkPackets (IPv4, IPv6, ICMP, Routing)
