Supported Protocols

Dissect Every Major Network Protocol

View Protocol Breakdown Guide
TCP
Transmission Control

Connection-oriented, reliable 3-way handshake with sequence & ack tracking.

Ports: 80, 443, 22, 21
UDP
User Datagram

Connectionless, lightweight transport optimized for low latency.

Ports: 53, 67, 123
ICMP
Control Message

Network diagnostics, ping echo requests, destination unreachable alerts.

Types: 0 (Reply), 8 (Request)
DNS
Domain Name System

Hostname resolution mapping human domains to IPv4 and IPv6 addresses.

Port: 53 (A, AAAA, MX)
HTTP
Hypertext Transfer

Web communication protocol with methods, headers, and status codes.

Port: 80, 8080
HTTPS / TLS
Secure Transport

Encrypted web transport; safe inspection without decryption tampering.

Port: 443, 8443
ARP
Address Resolution

Layer 2 broadcast protocol resolving IP addresses to physical MACs.

EtherType: 0x0806
IPv4 / IPv6
Internet Protocol

Layer 3 logical addressing, routing, packet fragmentation, and TTLs.

EtherType: 0x0800, 0x86dd
